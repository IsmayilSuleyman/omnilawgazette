# Omni Law Gazette — editorial rules

These rules govern every weekly gazette issue produced for Omni Law Firm.

- **Azerbaijani is the source-of-truth edition — author it FIRST.** The official material on e-qanun.az and the other portals is already in Azerbaijani. Compile the **complete Azerbaijani issue first, directly from that source-language material**, and only once a legitimate, finished Azerbaijani edition exists do you **translate it into English**. Never the reverse. When building the Azerbaijani edition, **stay faithful to the source: preserve the original legal wording and terminology without significant change** — do not loosely paraphrase or drift from the official text. Keep the register formal/legal. The English edition is a faithful translation of the Azerbaijani one.
- **Two separate editions, every issue.** Each issue is produced as **two distinct, mirror-image documents** — one entirely in **Azerbaijani** (primary), one entirely in **English** (translation) — never English only, and never both languages mixed in one document. The two editions are exact equivalents: same layout, same item order, same numbering, same content; only the language differs. This applies to all future issues. Deliver `.docx` + `.pdf` for each language (four files per issue), suffixed `-AZ` and `-EN`.
- **House format.** Follow the firm's example layout: A4, 0.5" margins; `omni law gazette` masthead + digest banner; full-width numbered lead (item 01); three-column body of numbered narrative articles; single-column footer. Each article = item number, kicker (`INSTITUTION · TYPE · DATE`), headline, short analytical prose, and a `Source ·` line.
- **Typography.** Body: Eloquia Text ExtLt 9pt. Kicker: Times New Roman 7pt bold, gold `#806000`, uppercase. Headline: Times New Roman 12pt bold, navy `#1F3864`. Source: Times New Roman 8pt italic, gold `#8A6D1E`. Item number: Eloquia, grey `#3B3838`.
- **Outputs.** Deliver both a native, editable **.docx** and a **.pdf**, generated by `scripts/build-gazette.py`.
- **Sourcing.** Compile from the Tier-1 official portals (president.az, nk.gov.az, meclis.gov.az, e-qanun.az, constcourt.gov.az). Verify dates/numbers against the source; never fabricate document numbers.
- **Source links point to e-qanun, as clickable hyperlinks.** Every article's `Source ·`/`Mənbə ·` line must link to the instrument's e-qanun framework page: `https://e-qanun.az/framework/<id>`. e-qanun is a JS SPA, but its backend API is usable: `https://api.e-qanun.az/framework/<id>` returns JSON with `requisite.citation` (document number), `acceptDate`, and `typeName`. Resolve each `<id>` by matching number + date + type to the document (IDs are sequential by registration, so scan the band around a known id). **Verify every id before citing it; never guess a framework number.** If an instrument is not yet on e-qanun (the register lags a few days), say so rather than inventing a link.
